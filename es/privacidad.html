Política de privacidad

Nos tomamos en serio su privacidad. En esta página encontrará información sobre los datos que pueden tratarse al visitar el sitio web El mundo de VinMat para niños y sobre la finalidad de dicho tratamiento.

Última actualización: julio de 2026

1. Datos que no recopilamos directamente

Para descargar nuestras actividades imprimibles no exigimos ningún registro, no creamos cuentas de usuario ni pedimos a los visitantes que faciliten datos personales.

Si se pone en contacto con nosotros por correo electrónico, podemos recibir su dirección de correo electrónico y la información que usted mismo incluya en el mensaje. Utilizamos estos datos únicamente para poder responderle.

2. Cookies y publicidad

El mundo de VinMat para niños puede utilizar Google AdSense para mostrar publicidad. Como este proyecto incluye contenido dirigido a niños, las solicitudes de anuncios correspondientes a contenido infantil no deben utilizar publicidad basada en intereses ni remarketing. Antes de activar la publicidad, el proyecto se configurará con el tratamiento restringido por edad de Google para contenido dirigido a niños.

Cuando esté permitido, Google puede seguir utilizando cookies limitadas, almacenamiento local o tecnologías similares para anuncios no personalizados o limitados, control de frecuencia, seguridad, prevención del fraude e informes agregados. Cuando la ley exija consentimiento, se ofrecerán opciones mediante una plataforma de gestión del consentimiento certificada por Google antes de utilizar cookies publicitarias o almacenamiento local.

Encontrará más información sobre cómo utiliza Google la información de sitios web y aplicaciones que usan sus servicios en la página Cómo utiliza Google la información de sitios web o aplicaciones.

3. Servicios de terceros

Nuestro sitio web puede utilizar servicios de terceros para el alojamiento, la seguridad, el análisis, la publicidad, el contenido integrado o el funcionamiento técnico del sitio. De acuerdo con sus propias políticas de privacidad, estos servicios pueden tratar información técnica, como el tipo de navegador, información sobre el dispositivo, las páginas visitadas, la ubicación aproximada, la dirección IP o las cookies.

4. Privacidad de los menores

El mundo de VinMat para niños ofrece actividades imprimibles para niños, pero el sitio web está dirigido principalmente a padres, tutores legales, docentes y otros adultos. No recopilamos deliberadamente datos personales de menores.

5. Enlaces externos

El sitio web puede contener enlaces a páginas externas, como redes sociales o servicios para apoyar voluntariamente el proyecto. No somos responsables del contenido ni de las políticas de privacidad de esos sitios web externos.

6. Cambios en esta política

Podemos actualizar esta política de privacidad periódicamente. La versión vigente se publicará siempre en esta página junto con la fecha de la última actualización.

7. Contacto

Si tiene alguna pregunta sobre esta política de privacidad, puede ponerse en contacto con nosotros por correo electrónico: vinmatforkids@gmail.com
